Use Case

1. Use Case

Actor เดียวคือผู้เยี่ยมชม (Guest) · เส้นประคือ include

Sequence

2.1 เรียกดู: หน้าแรก → รายการ (ค้นหา/กรอง/เรียง) → รายละเอียด

Browser เรียก Server (Next.js) ที่อ่านจาก PostgreSQL · URL ของรายการแชร์ได้

2.2 ตะกร้าและสรุปค่าใช้จ่าย (quote)

ตะกร้าอยู่ใน localStorage · server คำนวณราคาใหม่จาก DB และส่งคำเตือนเมื่อจำนวนเกิน stock

2.3 แนะนำฮวงจุ้ย

GET /api/feng-shui?room=&benefit= — rule-based จากข้อมูล seed

2.4 สลับภาษา (คง path และ query)

เปลี่ยน locale ใน URL และตั้ง cookie NEXT_LOCALE

Activity

3.1 ค้นหาและดูต้นไม้

จากหน้าแรกหรือค้นหา → กรอง → รายละเอียด → ใส่ตะกร้า (ถ้าต้องการ)

3.2 คำนวณค่าใช้จ่ายในตะกร้า

ค่าส่ง 60 บาท ฟรีเมื่อ subtotal ≥ 1,000 · VAT 7% รวมในราคาแล้ว · เตือนเมื่อเกิน stock

3.3 แนะนำฮวงจุ้ย

เลือกห้อง + เรื่องที่อยากเสริม → ต้นไม้ที่เหมาะ พร้อมทิศและเหตุผล
