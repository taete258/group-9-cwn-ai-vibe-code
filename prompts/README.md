# prompts/

พรอมต์ของผู้ใช้เรียงตามลำดับเวลา (ตัวต่อตัว ไม่สรุป) **กู้คืนจากข้อความที่ปรากฏในบทสนทนาของเซสชันนี้** ไม่ได้ดึงจากไฟล์บันทึกเซสชัน (ระบบไม่อนุญาตให้อ่านไฟล์นั้น)

ที่ยังไม่ครบ: พรอมต์ของขั้นก่อนหน้า (เช่น ตอนเขียน `spec.md`, `/speckit-plan`, `/speckit-tasks`, `/speckit-analyze` ที่ไม่ได้ส่งข้อความเพิ่ม) และข้อความ "ต่อเลย/ใช่" ระหว่างทางบางข้อที่ไม่ได้ถูกบันทึกในบทสนทนาที่ยังเหลือ ถ้าต้องการฉบับสมบูรณ์ให้ export จาก Claude Code โดยตรง
