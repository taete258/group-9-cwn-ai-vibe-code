คำสั่ง: /speckit-constitution

เขียน constitution v1.0.0 ของ Tree Shop ด้วย 7 หัวข้อ: 1) เงินเป็นสตางค์ (int) เสมอ ใช้ฟังก์ชันคำนวณตัวเดียวกันทั้ง client/server มี unit test 2) Server เป็นผู้ตัดสิน ไม่เชื่อราคา/stock จาก client ตัด stock ใน transaction (UPDATE ... WHERE stock >= qty) 3) สิทธิ์ตรวจที่ server ทุกครั้ง เช็ก userId ทุก query และ role ADMIN ที่ /admin และ /api/admin/* 4) สองภาษา th/en เสมอ ไม่ hardcode ข้อความ ข้อมูลสินค้าต้องกรอกครบสองภาษา 5) Test-first บนสัญญาข้อ 13 ของ spec.md ห้ามเปลี่ยนชื่อ/รูปแบบ endpoint, error code, data-testid 6) เรียบง่าย YAGNI ไม่ทำสิ่งในข้อ 10 นอกขอบเขต ให้จบใน workshop 7) Governance: วิธีแก้ constitution, semver, การตรวจก่อน merge. Tech stack: Next.js 16 + Prisma 7 + PostgreSQL 16 + next-intl + Docker Compose. อ้างอิง spec.md ที่ root
